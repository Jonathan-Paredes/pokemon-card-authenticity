# Results

This folder contains evaluation results, figures, and metrics for the trained model.

## Structure

results/
├── internal_test/ # Internal held-out test (558 images)
├── blind_test_262/ # Blind test (262 unseen cards, same protocol)
├── external_test_47/ # External test (47 new-expansion cards)
├── real_world_tests/ # Webcam + marketplace tests
├── cross_domain/ # iPhone ↔ OnePlus cross-domain experiments
├── gradcam/ # Grad-CAM visualizations
└── figures/ # Training curves, confusion matrices, summary plots


## Conventions

Each test folder contains:

| File | Description |
|---|---|
| `metrics.json` | Numerical results (accuracy, F1, AUC, per-domain metrics) |
| `predictions.csv` | Per-image predictions (path, label, prediction, probability) |
| `confusion_matrix.png` | Confusion matrix visualization (if applicable) |
| `report.txt` | Text summary (sklearn classification report) |
